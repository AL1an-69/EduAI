ЗАДАНИЕ 18 — ЗАДАЧА С ПАРАМЕТРОМ

КЛЮЧЕВЫЕ СЛОВА:
параметр, задача с параметром, при каких значениях параметра, уравнение с параметром, неравенство с параметром, число корней, графический метод

ЧТО ПРОВЕРЯЕТСЯ:
Исследование уравнений и неравенств в зависимости от параметра.

АЛГОРИТМ — ГРАФИЧЕСКИЙ МЕТОД:
Шаг 1: Перепиши уравнение так чтобы параметр был отдельно: f(x) = a
Шаг 2: Нарисуй график y = f(x)
Шаг 3: Параметр a — это горизонтальная прямая y = a
Шаг 4: Посчитай сколько точек пересечения при разных a

АЛГОРИТМ — АНАЛИТИЧЕСКИЙ МЕТОД:
Шаг 1: Выдели особые случаи (когда коэффициент при старшей степени = 0)
Шаг 2: Разбери каждый случай отдельно
Шаг 3: Для каждого случая найди условия на параметр

ТИПИЧНЫЕ ПОДХОДЫ:
Квадратное уравнение с параметром → дискриминант D ≥ 0 или D = 0 или D < 0
Линейное уравнение с параметром → проверь когда коэффициент = 0

ТИПИЧНЫЕ ОШИБКИ:
Не рассматривают особые случаи (деление на 0)
Неточно читают график при нахождении числа корней
