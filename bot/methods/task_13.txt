ЗАДАНИЕ 13 — УРАВНЕНИЯ (тригонометрические, показательные, логарифмические)

КЛЮЧЕВЫЕ СЛОВА:
уравнение, тригонометрическое уравнение, синус косинус тангенс, sin cos tg ctg, показательное уравнение, логарифмическое уравнение, log ln, решить уравнение, корни уравнения, ОДЗ

ЧТО ПРОВЕРЯЕТСЯ:
Решение сложных уравнений — тригонометрических, показательных, логарифмических.

АЛГОРИТМ ДЛЯ ТРИГОНОМЕТРИЧЕСКИХ УРАВНЕНИЙ:
Шаг 1: Упрости уравнение (замена, формулы)
Шаг 2: Сведи к простейшему виду sin x = a или cos x = a
Шаг 3: Запиши общее решение
Шаг 4: Найди конкретные значения если просят

АЛГОРИТМ ДЛЯ ЛОГАРИФМИЧЕСКИХ УРАВНЕНИЙ:
Шаг 1: Запиши ОДЗ (все подлогарифмические выражения > 0)
Шаг 2: Приведи к одному основанию
Шаг 3: Реши уравнение
Шаг 4: Проверь ответы на ОДЗ — отбрось лишние корни

АЛГОРИТМ ДЛЯ ПОКАЗАТЕЛЬНЫХ УРАВНЕНИЙ:
Шаг 1: Приведи к одному основанию или сделай замену t = aˣ
Шаг 2: Реши полученное уравнение
Шаг 3: Найди x из замены

КЛЮЧЕВЫЕ ФОРМУЛЫ:
sin x = a: x = arcsin a + 2πn, x = π - arcsin a + 2πn
cos x = a: x = ±arccos a + 2πn
tg x = a: x = arctg a + πn
log_a(f) = log_a(g) → f = g при ОДЗ
aᶠ⁽ˣ⁾ = aᵍ⁽ˣ⁾ → f(x) = g(x)

ТИПИЧНЫЕ ОШИБКИ:
Забывают проверять ОДЗ в логарифмических уравнениях
Теряют половину корней в тригонометрических уравнениях
Неправильно делают замену переменной
