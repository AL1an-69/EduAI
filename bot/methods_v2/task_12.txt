ЗАДАНИЕ 12 — НАИБОЛЬШЕЕ И НАИМЕНЬШЕЕ ЗНАЧЕНИЕ

ИСТОЧНИК ФОРМУЛ: Справочник ЕГЭ по математике, Анна Малкова (ege-study.ru)

КЛЮЧЕВЫЕ СЛОВА:
наибольшее значение, наименьшее значение, максимум, минимум,
на отрезке, на промежутке, на интервале,
найдите наибольшее, найдите наименьшее,
глобальный максимум, глобальный минимум, локальный экстремум,
функция на замкнутом отрезке, ограниченная область,
целевая функция, оптимизация, наиболее выгодный, наименьшие затраты,
производная, критическая точка, f'(x) = 0

ЧТО ПРОВЕРЯЕТСЯ:
Умение находить наибольшее и наименьшее значение функции на заданном отрезке с применением производной.

АЛГОРИТМ РЕШЕНИЯ:

Шаг 1: Найди производную f'(x).

Шаг 2: Реши уравнение f'(x) = 0 — найди критические точки.

Шаг 3: Отбери только те критические точки, которые лежат ВНУТРИ заданного отрезка [a; b].

Шаг 4: Вычисли значения функции:
  — в каждой отобранной критической точке
  — в левом конце отрезка: f(a)
  — в правом конце отрезка: f(b)

Шаг 5: Из всех полученных значений выбери наибольшее и наименьшее.

Шаг 6: Запиши ответ.

ВАЖНО (из справочника Малковой):
Наибольшее и наименьшее значения непрерывной функции на отрезке достигаются
ЛИБО в точках экстремума, ЛИБО на концах отрезка.

Точка максимума — значение функции в ней больше, чем в соседних («холмик»).
Точка минимума — значение функции в ней меньше, чем в соседних («ямка»).
В точке максимума f'(x) = 0, знак f' меняется с «+» на «–».
В точке минимума f'(x) = 0, знак f' меняется с «–» на «+».

Таблица поведения функции (из справочника):
  f(x): возрастает | max | убывает | min | возрастает
  f'(x):    +      |  0  |    –    |  0  |     +

КЛЮЧЕВЫЕ ФОРМУЛЫ:

f'(x) = 0 — условие критической точки
Значения сравниваем: f(x_крит), f(a), f(b)
Наибольшее: max{f(a), f(b), f(x_крит₁), f(x_крит₂), ...}
Наименьшее: min{f(a), f(b), f(x_крит₁), f(x_крит₂), ...}

Для квадратной функции y = ax² + bx + c:
  Вершина параболы: x₀ = -b / (2a)
  a > 0: ветви вверх, x₀ — точка минимума
  a < 0: ветви вниз, x₀ — точка максимума

Для всей числовой прямой (без отрезка):
  Используй только критические точки + знак производной.

ТИПИЧНЫЕ ОШИБКИ:

- Не проверяют концы отрезка — берут только критические точки.
  Наибольшее/наименьшее может быть на краю!
- Критическую точку вне отрезка включают в сравнение — нельзя!
- Путают «наибольшее значение функции» (число f(x)) и «точку максимума» (значение x).
- При нахождении производной допускают ошибки → неверные критические точки.
- Не подставляют все найденные точки — пропускают одну.

ПРИМЕР 1:
Задача: Найдите наибольшее и наименьшее значения f(x) = x³ - 3x + 2 на [-2; 3].
Решение:
f'(x) = 3x² - 3 = 3(x-1)(x+1)
f'(x) = 0 → x = 1 и x = -1. Оба в [-2; 3].
Вычислим:
  f(-2) = -8 + 6 + 2 = 0
  f(-1) = -1 + 3 + 2 = 4
  f(1)  = 1 - 3 + 2 = 0
  f(3)  = 27 - 9 + 2 = 20
Наибольшее: f(3) = 20. Наименьшее: f(-2) = f(1) = 0.
Ответ: наибольшее = 20, наименьшее = 0

ПРИМЕР 2:
Задача: Найдите наибольшее значение f(x) = -2x² + 8x - 3.
Решение:
f'(x) = -4x + 8
f'(x) = 0 → x = 2 — вершина параболы (a = -2 < 0) → максимум.
f(2) = -8 + 16 - 3 = 5
Ответ: наибольшее значение = 5 при x = 2

ПРИМЕР 3:
Задача: Найдите наименьшее значение f(x) = x + 4/x при x > 0.
Решение:
f'(x) = 1 - 4/x²
f'(x) = 0 → x² = 4 → x = 2
Знак: при x < 2: f'(x) < 0; при x > 2: f'(x) > 0 → x = 2 минимум.
f(2) = 2 + 4/2 = 4
Ответ: наименьшее значение = 4 при x = 2
