ЧТО ПРОВЕРЯЕТСЯ:
Умение применять производную как скорость изменения функции в прикладном контексте — физическом, экономическом, техническом.

АЛГОРИТМ РЕШЕНИЯ:

Шаг 1: Прочитай условие и определи, какая величина описана функцией. Обычно это S(t) — путь, H(t) — высота, Q(t) — количество, T(t) — температура и т.д.

Шаг 2: Определи, что нужно найти:
  — если нужна скорость в момент t₀ → найди S'(t₀)
  — если нужно, когда скорость максимальна → найди производную скорости v'(t) = 0
  — если нужно расстояние или значение → подставь t в S(t)
  — если нужен момент остановки → реши v(t) = S'(t) = 0

Шаг 3: Выполни нужное математическое действие (производная, подстановка, решение уравнения).

Шаг 4: Проверь, входит ли найденное t в допустимый диапазон (t ≥ 0).

Шаг 5: Запиши ответ с единицами измерения (м/с, м, с и т.д.).

КЛЮЧЕВЫЕ ФОРМУЛЫ (из справочника Малковой):

--- ПРОИЗВОДНАЯ КАК СКОРОСТЬ ИЗМЕНЕНИЯ (из справочника) ---
Производная — это скорость изменения функции.
f'(x₀) = угловой коэффициент касательной к графику в точке x₀ = tg(α)

Если f'(x) > 0 → функция f(x) возрастает.
Если f'(x) < 0 → функция f(x) убывает.
В точке максимума: f'(x) = 0, знак меняется с «+» на «–».
В точке минимума: f'(x) = 0, знак меняется с «–» на «+».

Таблица поведения:
  f(x): возрастает | max | убывает | min | возрастает
  f'(x):    +      |  0  |    –    |  0  |     +

--- МЕХАНИЧЕСКОЕ ДВИЖЕНИЕ ---
Скорость: v(t) = S'(t)         [производная пути по времени]
Ускорение: a(t) = v'(t) = S''(t)

Тело остановилось: v(t) = S'(t) = 0
Максимальная высота: H'(t) = 0 → найти t, затем H(t)
Путь за время от t₁ до t₂: S(t₂) - S(t₁)

--- ДЛЯ КВАДРАТНОЙ ФУНКЦИИ f(t) = at² + bt + c ---
Максимум/минимум: t = -b / (2a)

--- ДРУГИЕ ПРИКЛАДНЫЕ ФОРМУЛЫ ---
Мощность: P = A / t   (работа / время)
Средняя скорость = весь путь / всё время  (S = v * t → v_ср = S_полн / t_полн)
Производительность = работа в единицу времени

ТИПИЧНЫЕ ОШИБКИ:

- Путают скорость v(t) = S'(t) и само значение пути S(t) — это разные вещи.
- При нахождении максимальной скорости ищут максимум S(t), а не v'(t) = 0.
- Забывают про t ≥ 0 — время не может быть отрицательным.
- Путают «в какой момент» (найти t) и «чему равно значение» (подставить t).
- При производной числитель/знаменатель путают с правилами табличных производных.

ПРИМЕР 1:
Задача: Точка движется по закону S(t) = 3t² - 12t + 5, где S в метрах, t в секундах. Найдите скорость точки в момент t = 4 с.
Решение:
v(t) = S'(t) = 6t - 12
v(4) = 6*4 - 12 = 24 - 12 = 12 м/с
Ответ: 12 м/с

ПРИМЕР 2:
Задача: Тело брошено вертикально вверх. Высота H(t) = 20t - 5t² (метры, секунды). Найдите максимальную высоту и время её достижения.
Решение:
H'(t) = 20 - 10t
H'(t) = 0 → t = 2 с
H(2) = 20*2 - 5*4 = 40 - 20 = 20 м
Проверка: H''(t) = -10 < 0 → это максимум.
Ответ: максимальная высота 20 м через 2 с

ПРИМЕР 3:
Задача: Скорость тела v(t) = t² - 6t + 8 (м/с). Найдите моменты остановки.
Решение:
v(t) = 0: t² - 6t + 8 = 0
D = 36 - 32 = 4
t₁ = 2 с, t₂ = 4 с
Ответ: тело останавливается при t = 2 с и t = 4 с
