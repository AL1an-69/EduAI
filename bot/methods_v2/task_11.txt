ЗАДАНИЕ 11 — ГРАФИКИ ФУНКЦИЙ

ИСТОЧНИК ФОРМУЛ: Справочник ЕГЭ по математике, Анна Малкова (ege-study.ru)

КЛЮЧЕВЫЕ СЛОВА:
график функции, возрастает, убывает, промежуток возрастания, убывания,
нули функции, точка максимума, минимума, наибольшее, наименьшее,
чётная функция, нечётная, периодическая функция, обратная функция,
показательная функция, логарифм, синус, косинус, тангенс,
область определения, область значений, f(-x) = f(x), f(-x) = -f(x),
преобразование графиков: сдвиг, отражение, растяжение, сжатие,
f(x+a) сдвиг влево, f(x-a) сдвиг вправо, f(x)+a сдвиг вверх,
y = f(|x|), y = |f(x)|, y = -f(x), y = f(-x)

ЧТО ПРОВЕРЯЕТСЯ:
Умение читать и анализировать графики функций, применять преобразования.

АЛГОРИТМ РЕШЕНИЯ:

Шаг 1: Определи тип функции по графику или формуле.
Шаг 2: Ответь на вопрос:
  — Нули: где график пересекает ось Ox
  — Значение в точке: по x найти y на графике
  — Возрастание: график идёт «снизу-вверх» слева направо (f'(x) > 0)
  — Убывание: график идёт «сверху-вниз» (f'(x) < 0)
  — Максимум: «холмик», минимум: «ямка»
  — Знак функции: где выше Ox (f > 0), где ниже (f < 0)

Шаг 3: При преобразовании графика применяй правила сдвигов.

Шаг 4: При решении уравнения f(x) = c по графику: проведи горизонтальную прямую y = c, найди пересечения.

КЛЮЧЕВЫЕ ФОРМУЛЫ (из справочника Малковой):

--- СВОЙСТВА ФУНКЦИЙ ---
Функция y = f(x) возрастает: для x₁ > x₂ → f(x₁) > f(x₂)
Функция убывает: для x₁ > x₂ → f(x₁) < f(x₂)
Точка максимума: значение больше, чем у соседних («холмик»)
Точка минимума: значение меньше, чем у соседних («ямка»)
Наибольшее/наименьшее значение на отрезке: в экстремуме или на конце отрезка.

Нули функции: f(x) = 0 (точки пересечения с осью Ox)
f(x) > 0: функция положительна (график выше Ox)
f(x) < 0: функция отрицательна (график ниже Ox)

--- ЧЁТНОСТЬ И НЕЧЁТНОСТЬ ---
Чётная: f(-x) = f(x) → симметрична относительно оси Oy
  Примеры: y = x², y = cos(x), y = |x|
Нечётная: f(-x) = -f(x) → симметрична относительно начала координат
  Примеры: y = x³, y = sin(x), y = tg(x), y = x/2

--- ПЕРИОДИЧНОСТЬ ---
Периодическая: f(x+T) = f(x) — T наименьший положительный период
  y = sin(x), y = cos(x), y = tg(x), y = ctg(x) — периодические функции

--- ОБРАТНАЯ ФУНКЦИЯ ---
f и g обратны: f(g(x)) = x
Графики взаимно обратных функций симметричны относительно y = x.
  Пример: y = aˣ и y = log_a(x); y = x² (x≥0) и y = √x

--- ПРЕОБРАЗОВАНИЯ ГРАФИКОВ (правила из справочника) ---
y = f(x+a): сдвиг влево на a (при a > 0)
y = f(x-a): сдвиг вправо на a
y = f(x) + a: сдвиг вверх на a
y = f(x) - a: сдвиг вниз на a
y = f(-x): отражение относительно оси Oy
y = -f(x): отражение относительно оси Ox
y = f(kx) (k>1): сжатие по горизонтали в k раз
y = k*f(x) (k>1): растяжение по вертикали в k раз

y = f(|x|): правая часть зеркально отображается в левую
y = |f(x)|: часть графика ниже Ox отражается вверх

--- ПОКАЗАТЕЛЬНАЯ y = aˣ ---
При a > 1: возрастает, проходит через (0; 1)
При 0 < a < 1: убывает, проходит через (0; 1)

--- ЛОГАРИФМИЧЕСКАЯ y = log_a(x) ---
При a > 1: возрастает, x > 0
При 0 < a < 1: убывает, x > 0

--- ЛИНЕЙНАЯ y = kx + b ---
k > 0: возрастает; k < 0: убывает
Если k₁ = k₂: прямые параллельны
Если k₁ * k₂ = -1: прямые перпендикулярны

ТИПИЧНЫЕ ОШИБКИ:

- Путают промежутки возрастания с промежутками, где f > 0 (разные понятия).
- Нули функции — это x-координаты пересечений с осью Ox, а не y.
- При сдвиге f(x+2) — это сдвиг ВЛЕВО на 2, а не вправо.
- Для обратной функции: не пересечение с y = x, а симметрия относительно неё.
- При y = |f(x)| не отражают всю часть ниже Ox, а только её часть.

ПРИМЕР 1:
Задача: Функция y = x² - 4x + 3. Нули, вершина, промежутки возрастания.
Решение:
Нули: x² - 4x + 3 = 0, x = 1 и x = 3
Вершина: x = 2, y = 4 - 8 + 3 = -1
a = 1 > 0 → ветви вверх, x = 2 — минимум
Убывает на (-∞; 2), возрастает на (2; +∞)
f > 0 при x < 1 и x > 3
Ответ: нули x=1, x=3; возрастает на (2; +∞)

ПРИМЕР 2:
Задача: Какое преобразование переводит y = sin(x) в y = sin(2x)?
Решение:
y = sin(2x) = f(2x) — сжатие по горизонтали в 2 раза. Период стал π вместо 2π.
Ответ: сжатие по горизонтали в 2 раза

ПРИМЕР 3:
Задача: Чётная или нечётная: f(x) = x³ + x?
Решение:
f(-x) = (-x)³ + (-x) = -x³ - x = -(x³ + x) = -f(x) → нечётная.
Ответ: нечётная
