КЛЮЧЕВЫЕ ФОРМУЛЫ (из справочника Малковой):

--- ФОРМУЛЫ СОКРАЩЁННОГО УМНОЖЕНИЯ ---
a² - b² = (a-b)(a+b)             [разность квадратов]
(a+b)² = a² + 2ab + b²           [квадрат суммы]
(a-b)² = a² - 2ab + b²           [квадрат разности]
(a+b)³ = a³ + 3a²b + 3ab² + b³
(a-b)³ = a³ - 3a²b + 3ab² - b³
a³ + b³ = (a+b)(a² - ab + b²)
a³ - b³ = (a-b)(a² + ab + b²)

ЛАЙФХАК: числа на 5 в квадрате мгновенно.
  Число вида А5: умножаем А на (А+1) и приписываем 25.
  45² = 4*5=20, приписываем 25 → 2025
  85² = 8*9=72 → 7225

--- ПРАВИЛА СТЕПЕНЕЙ ---
aᵐ * aⁿ = aᵐ⁺ⁿ
aᵐ / aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
aⁿ * bⁿ = (ab)ⁿ
aⁿ / bⁿ = (a/b)ⁿ
a⁰ = 1  (a ≠ 0)
a⁻ⁿ = 1/aⁿ
a^(1/n) = ⁿ√a
a^(m/n) = ⁿ√(aᵐ)  (при a > 0)

--- КОРНИ ---
√(ab) = √a * √b  (a ≥ 0, b ≥ 0)
√(a/b) = √a / √b  (a ≥ 0, b > 0)
(√a)² = a  (a ≥ 0)
√(a²) = |a|
ⁿ√(aᵐ) = a^(m/n)  (a > 0)
Корень чётной степени → только из неотрицательных чисел.
Корень нечётной степени → из любых чисел.

--- ЛОГАРИФМЫ ---
log_a(b) = c  ⟺  aᶜ = b   (b>0, a>0, a≠1)
log_a(b*c) = log_a(b) + log_a(c)
log_a(b/c) = log_a(b) - log_a(c)
log_a(bᵐ) = m * log_a(b)
log_a(a) = 1
log_a(1) = 0
Формула перехода: log_a(b) = log_c(b) / log_c(a)
                  log_a(b) = 1 / log_b(a)
Основное тождество: a^(log_a(b)) = b

lg = log₁₀ (десятичный), ln = log_e (натуральный, e ≈ 2,718)

ТИПИЧНЫЕ ОШИБКИ:

- √(a+b) ≠ √a + √b. Корень суммы ≠ сумма корней!
- При делении степеней: вычитают показатели, а не делят.
- Логарифм отрицательного числа не существует.
- Путают lg (основание 10) и ln (основание e).
- При возведении отрицательного числа в степень: (-2)² = 4, но -(2²) = -4.

ПРИМЕР 1:
Задача: Вычислите 27^(2/3) / 9^(1/2) * 3^(-1).
Решение:
27^(2/3) = (³√27)² = 3² = 9
9^(1/2) = 3
3^(-1) = 1/3
(9 / 3) * (1/3) = 3 * (1/3) = 1
Ответ: 1

ПРИМЕР 2:
Задача: Вычислите log₂(8) + log₂(4) - log₂(2).
Решение:
log₂(8) = 3, log₂(4) = 2, log₂(2) = 1
3 + 2 - 1 = 4
Ответ: 4

ПРИМЕР 3:
Задача: Упростите √48 - √27 + √75.
Решение:
√48 = 4√3, √27 = 3√3, √75 = 5√3
4√3 - 3√3 + 5√3 = 6√3
Ответ: 6√3
