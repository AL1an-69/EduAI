ЧТО ПРОВЕРЯЕТСЯ:
Умение решать различные типы неравенств и записывать ответ в виде числового промежутка.

АЛГОРИТМ РЕШЕНИЯ:

-- КВАДРАТНОЕ НЕРАВЕНСТВО (ax² + bx + c > 0) --
Шаг 1: Найди корни ax² + bx + c = 0 (если D > 0, x₁ < x₂).
Шаг 2: Нарисуй параболу (ветви вверх при a > 0, вниз при a < 0).
Шаг 3: Определи, где парабола выше/ниже оси Ox.
При a > 0:
  ax² + bx + c > 0: x < x₁ или x > x₂  (снаружи корней)
  ax² + bx + c < 0: x₁ < x < x₂  (между корнями)
При a < 0: всё наоборот.

-- МЕТОД ИНТЕРВАЛОВ (из справочника Малковой) --
Применяется для вида (x-a)(x-b) / (x-c)(x-d) ≥ 0

Шаг 1: Всё перенеси в левую часть, справа 0.
Шаг 2: Найди нули числителя (= 0) и знаменателя (не существует).
Шаг 3: Отметь все точки на числовой оси.
Шаг 4: Знак в крайнем правом промежутке: подставь число больше всех точек.
Шаг 5: Чередуй знаки слева.
  ИСКЛЮЧЕНИЕ: кратный корень (фактор в чётной степени) — знак НЕ меняется!
Шаг 6: Отметь нужные промежутки (по знаку неравенства).
  — Нули числителя включаются при ≥ или ≤
  — Нули знаменателя НИКОГДА не включаются

-- ПОКАЗАТЕЛЬНОЕ НЕРАВЕНСТВО --
a^f(x) > a^g(x):
  Если a > 1: f(x) > g(x)  (знак сохраняется)
  Если 0 < a < 1: f(x) < g(x)  (знак меняется!)

-- ЛОГАРИФМИЧЕСКОЕ НЕРАВЕНСТВО --
Шаг 1: ОДЗ: аргументы > 0.
Шаг 2: log_a(f) > log_a(g) (при a > 1): f > g
        log_a(f) > log_a(g) (при 0 < a < 1): f < g (знак меняется!)
Шаг 3: Пересечь с ОДЗ.

КЛЮЧЕВЫЕ ФОРМУЛЫ (из справочника Малковой):

--- КВАДРАТНЫЕ НЕРАВЕНСТВА (таблица) ---
a > 0, D > 0, корни x₁ < x₂:
  ax²+bx+c > 0: x∈(-∞;x₁)∪(x₂;+∞)
  ax²+bx+c < 0: x∈(x₁;x₂)
  ax²+bx+c ≤ 0: x∈[x₁;x₂]
  ax²+bx+c ≥ 0: x∈(-∞;x₁]∪[x₂;+∞)

a > 0, D < 0:
  ax²+bx+c > 0: всё R (любые x)
  ax²+bx+c < 0: нет решений

a > 0, D = 0, корень x₀:
  ax²+bx+c > 0: все x кроме x₀
  ax²+bx+c ≤ 0: только x = x₀

--- ПОКАЗАТЕЛЬНЫЕ НЕРАВЕНСТВА (из справочника) ---
a > 1: a^x₁ < a^x₂  ⟺  x₁ < x₂
0 < a < 1: a^x₁ < a^x₂  ⟺  x₁ > x₂  (больше аргумент → меньше значение)

--- ЛОГАРИФМИЧЕСКИЕ НЕРАВЕНСТВА ---
a > 1: log_a(x₁) < log_a(x₂)  ⟺  x₁ < x₂
0 < a < 1: log_a(x₁) < log_a(x₂)  ⟺  x₁ > x₂

ТИПИЧНЫЕ ОШИБКИ:

- При умножении/делении на отрицательное число знак неравенства не меняется — ошибка!
- Нули знаменателя включают в ответ при ≥ или ≤ — нельзя!
- Для показательных/логарифмических неравенств с основанием < 1 не меняют знак.
- В логарифмических неравенствах не применяют ОДЗ.
- Путают объединение (совокупность) и пересечение (система) промежутков.

ПРИМЕР 1:
Задача: Решите x² - 5x + 6 < 0.
Решение:
Корни: x = 2, x = 3. a=1>0, парабола вверх.
x² - 5x + 6 < 0 — между корнями: 2 < x < 3
Ответ: x ∈ (2; 3)

ПРИМЕР 2 (метод интервалов из справочника):
Задача: (x-a)²*(x-b) / ((x-c)*(x-d)) ≥ 0
Решение:
Точки: a, b, c, d.
Кратный корень a (степень 2) — знак НЕ меняется при переходе через a.
Знак в крайнем правом промежутке: «+».
Ответ: x ∈ {a} ∪ [b; c) ∪ (d; +∞)

ПРИМЕР 3:
Задача: Решите log₀.₅(x-2) < log₀.₅(5-x).
Решение:
ОДЗ: x-2>0 и 5-x>0 → 2<x<5
Основание 0,5 < 1 → знак меняется: x-2 > 5-x
2x > 7 → x > 3,5
Пересечение с ОДЗ: 3,5 < x < 5
Ответ: x ∈ (3,5; 5)
