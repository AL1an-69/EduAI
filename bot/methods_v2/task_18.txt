АЛГОРИТМ РЕШЕНИЯ:

-- МЕТОД 1: ГРАФИЧЕСКИЙ (f(x) = a) --
Шаг 1: Построй (мысленно) график функции y = f(x).
Шаг 2: Задача «при каком a уравнение f(x) = a имеет k решений» — это:
  при каком a горизонтальная прямая y = a пересекает график f(x) ровно в k точках.
Шаг 3: Определи характерные значения f(x): локальные максимумы, минимумы, концы области.
Шаг 4: Запиши ответ: a ∈ (промежуток).

-- МЕТОД 2: АНАЛИТИЧЕСКИЙ --
Шаг 1: Запиши уравнение как зависимость a от x: a = g(x).
Шаг 2: Исследуй функцию a = g(x): область значений, экстремумы.
Шаг 3: Определи, при каких значениях a нужное число решений.

-- ДЛЯ КВАДРАТНОГО УРАВНЕНИЯ --
Шаг 1: D = b² - 4ac (зависит от a).
Нет решений: D < 0;  Одно: D = 0;  Два: D > 0.
Шаг 2: Реши неравенство/уравнение относительно a.

КЛЮЧЕВЫЕ ФОРМУЛЫ:

--- ДИСКРИМИНАНТ ---
ax² + bx + c = 0: D = b² - 4ac
  D < 0: нет корней; D = 0: один; D > 0: два.

--- ДЛЯ УРАВНЕНИЯ f(x) = a ---
Число решений = число точек пересечения y = f(x) и y = a.
Касание: ровно 1 точка пересечения → D = 0.

«БАЗОВЫЕ ЭЛЕМЕНТЫ» ДЛЯ ЗАДАЧ С ПАРАМЕТРАМИ (из справочника Малковой, стр. 79-82):

1. Окружность: x² + y² = R²
   — центр (0,0), радиус |R|.
   Пример: x² + y² = 4 — окружность, R = 2.

2. Окружность со сдвигом: (x-a)² + (y-b)² = R²
   — центр P(a; b), радиус |R|.
   Пример: (x+2)² + (y+1)² = 9 — центр (-2; -1), R = 3.

3. Круг: (x-a)² + (y-b)² ≤ R²
   — замкнутый круг с границей.

4. Верхняя полуокружность: y = √(R² - x²)
   — центр (0,0), R, y ≥ 0.
   Пример: y = √(9 - x²)

5. Нижняя полуокружность: y = -√(R² - x²)
   — центр (0,0), R, y ≤ 0.
   Пример: y = -√(9 - x²)

6. Полуокружность со сдвигом: y = √(R² - (x-a)²) + b
   — центр (a; b), верхняя полуокружность.

7. Ромб: a|x| + b|y| = c  (при a,b,c > 0)
   — симметричен относительно начала координат.
   Пример: 3|x| + 2|y| = 6

8. Сумма модулей: y = |x-a| + |x-b|
   — «угловая» функция, минимум = |a-b| на промежутке [a; b].

9. Расстояние между точками A(x₁,y₁) и B(x₂,y₂):
   AB = √((x₂-x₁)² + (y₂-y₁)²)

   Координаты середины отрезка AB:
   Xм = (x₁+x₂)/2;  Yм = (y₁+y₂)/2

ТИПИЧНЫЕ ОШИБКИ:

- Не рассматривают все случаи (при a = 0 поведение функции может меняться).
- Путают строгие и нестрогие неравенства при формулировке ответа.
- При графическом методе неверно определяют максимумы/минимумы функции.
- Забывают проверить граничные значения (включать ли концы промежутка).
- Из D = 0 получают уравнение, но берут корень с неверным знаком.
- Не замечают геометрический смысл задачи: f(x) = a — прямая y = a пересекает кривую.

ПРИМЕР 1:
Задача: При каких значениях a уравнение x² - 4x + a = 0 имеет два различных корня?
Решение:
D = 16 - 4a. Два корня: D > 0 → a < 4.
Ответ: a ∈ (-∞; 4)

ПРИМЕР 2:
Задача: При каком a прямая y = a касается графика y = x² - 2x + 3?
Решение:
x² - 2x + 3 = a → x² - 2x + (3-a) = 0
D = 4 - 4(3-a) = 4a - 8
D = 0 → a = 2. Проверка: минимум параболы при x = 1: f(1) = 2 ✓
Ответ: a = 2

ПРИМЕР 3:
Задача: При каких значениях a уравнение |x² - 4| = a имеет ровно 4 решения?
Решение:
График y = |x² - 4|: максимум 4 при x = 0, минимум 0 при x = ±2, затем растёт.
Прямая y = a пересекает график в 4 точках при 0 < a < 4.
Ответ: a ∈ (0; 4)
