ЗАДАНИЕ 13 — УРАВНЕНИЯ (ТРИГОНОМЕТРИЯ, ЛОГАРИФМЫ, ПОКАЗАТЕЛЬНЫЕ)

ИСТОЧНИК ФОРМУЛ: Справочник ЕГЭ по математике, Анна Малкова (ege-study.ru)

КЛЮЧЕВЫЕ СЛОВА:
тригонометрическое уравнение, логарифмическое уравнение, показательное уравнение,
sin x = a, cos x = a, tg x = a, ctg x = a, arcsin, arccos, arctg, arcctg,
log, ln, lg, логарифм, основание, показатель,
2^x = 8, e^x, a^x = b, показательная функция,
однородное уравнение, метод замены, t = sin x, t = 2^x,
ОДЗ логарифма, корни на отрезке, количество корней, общее решение

ЧТО ПРОВЕРЯЕТСЯ:
Умение решать тригонометрические, логарифмические и показательные уравнения, а также их комбинации.

АЛГОРИТМ РЕШЕНИЯ:

-- ПОКАЗАТЕЛЬНОЕ УРАВНЕНИЕ --
Шаг 1: Приведи к одному основанию: a^f(x) = a^g(x) → f(x) = g(x)
Шаг 2: Если разные основания — вводи замену t = a^x или логарифмируй.
Шаг 3: Реши полученное уравнение.

-- ЛОГАРИФМИЧЕСКОЕ УРАВНЕНИЕ --
Шаг 1: ОДЗ: аргументы > 0.
Шаг 2: Приведи к виду log_a(f) = log_a(g) → f = g
         Или log_a(f) = b → f = a^b
Шаг 3: Реши и проверь ОДЗ.

-- ТРИГОНОМЕТРИЧЕСКОЕ УРАВНЕНИЕ --
Шаг 1: Приведи к стандартной форме sin x = a, cos x = a, и т.д.
Шаг 2: При сложных уравнениях — замена t = sin x или использование формул тригонометрии.
Шаг 3: Запиши общее решение.
Шаг 4: При нужде — найди корни на заданном промежутке.

КЛЮЧЕВЫЕ ФОРМУЛЫ (из справочника Малковой):

--- ПОКАЗАТЕЛЬНЫЕ ---
a^f(x) = a^g(x) → f(x) = g(x)  (при a > 0, a ≠ 1)

--- ЛОГАРИФМИЧЕСКИЕ ---
log_a(x) = b → x = a^b
log_a(f) = log_a(g) → f = g  (при f, g > 0)
Основные свойства:
  log_a(bc) = log_a(b) + log_a(c)
  log_a(b/c) = log_a(b) - log_a(c)
  log_a(b^m) = m * log_a(b)
  log_a(a) = 1, log_a(1) = 0
Формула перехода: log_a(b) = log_c(b) / log_c(a) = 1 / log_b(a)
Основное тождество: a^(log_a(b)) = b

--- ТРИГОНОМЕТРИЧЕСКИЕ (из справочника Малковой) ---
Стандартные решения:
  sin x = a  (|a| ≤ 1): x = (-1)ⁿ * arcsin(a) + πn, n∈Z
  cos x = a  (|a| ≤ 1): x = ± arccos(a) + 2πn, n∈Z
  tg x = a: x = arctg(a) + πn, n∈Z
  ctg x = a: x = arcctg(a) + πn, n∈Z

Частные случаи:
  sin x = 0 → x = πn
  sin x = 1 → x = π/2 + 2πn
  sin x = -1 → x = -π/2 + 2πn
  cos x = 0 → x = π/2 + πn
  cos x = 1 → x = 2πn
  cos x = -1 → x = π + 2πn
  tg x = 0 → x = πn

Определения:
  arcsin a — число φ ∈ [-π/2; π/2], такое что sin φ = a
  arccos a — число φ ∈ [0; π], такое что cos φ = a
  arctg a — число φ ∈ (-π/2; π/2), такое что tg φ = a

ТРИГОНОМЕТРИЧЕСКИЕ ФОРМУЛЫ (для упрощения):
  sin²x + cos²x = 1
  sin(2x) = 2sin(x)cos(x)
  cos(2x) = cos²x - sin²x = 1 - 2sin²x = 2cos²x - 1
  sin²x = (1 - cos(2x)) / 2
  cos²x = (1 + cos(2x)) / 2
  tg²x + 1 = 1/cos²x
  tg(x) = sin(x)/cos(x)

ФОРМУЛЫ ПРИВЕДЕНИЯ (из справочника Малковой):
  При прибавлении нечётного * π/2: функция меняется на кофункцию (sin↔cos, tg↔ctg).
  При прибавлении чётного * π/2: функция НЕ меняется.
  Знак определяется по четверти.
  cos(x + π/2) = -sin x
  cos(x + 3π/2) = sin x
  sin(π - x) = sin x
  cos(π - x) = -cos x
  sin(π + x) = -sin x
  cos(π + x) = -cos x

ТИПИЧНЫЕ ОШИБКИ:

- В логарифмическом уравнении не проверяют ОДЗ — ответ, при котором аргумент ≤ 0.
- В показательном уравнении приравнивают показатели при разных основаниях без приведения.
- В тригонометрическом уравнении путают формулы sin и cos.
- Для tg и ctg периодичность π, а не 2π.
- При замене t = sin x забывают ограничение -1 ≤ t ≤ 1.

ПРИМЕР 1:
Задача: Решите уравнение 4^x - 6 * 2^x + 8 = 0.
Решение:
Замена t = 2^x, t > 0. 4^x = t².
t² - 6t + 8 = 0, D = 36-32 = 4
t₁ = 4, t₂ = 2
2^x = 4 → x = 2; 2^x = 2 → x = 1
Ответ: x = 1, x = 2

ПРИМЕР 2:
Задача: Решите log₂(x-1) + log₂(x+1) = 3.
Решение:
ОДЗ: x - 1 > 0 и x + 1 > 0 → x > 1.
log₂((x-1)(x+1)) = 3 → x² - 1 = 8 → x² = 9 → x = ±3
Проверка ОДЗ: x = 3 > 1 ✓; x = -3 — нет.
Ответ: x = 3

ПРИМЕР 3:
Задача: Решите 2sin²x - 3sin x + 1 = 0.
Решение:
Замена t = sin x, -1 ≤ t ≤ 1.
2t² - 3t + 1 = 0, t₁ = 1, t₂ = 1/2
sin x = 1 → x = π/2 + 2πn
sin x = 1/2 → x = π/6 + 2πn  ИЛИ  x = 5π/6 + 2πn
Ответ: x = π/2 + 2πn; x = π/6 + 2πn; x = 5π/6 + 2πn, n∈Z
