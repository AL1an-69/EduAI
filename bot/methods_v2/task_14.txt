ЧТО ПРОВЕРЯЕТСЯ:
Умение находить углы и расстояния в пространственных фигурах координатным методом.

АЛГОРИТМ РЕШЕНИЯ (координатный метод):

Шаг 1: Введи систему координат. В прямоугольном параллелепипеде — рёбра вдоль осей.

Шаг 2: Запиши координаты всех вершин.

Шаг 3: В зависимости от задачи:

  УГОЛ МЕЖДУ ПРЯМЫМИ (через направляющие векторы a, b):
    cos α = |a·b| / (|a|*|b|)  → берём модуль, чтобы угол ≤ 90°

  УГОЛ МЕЖДУ ПРЯМОЙ И ПЛОСКОСТЬЮ (вектор прямой a, нормаль плоскости n):
    sin α = |a·n| / (|a|*|n|)

  УГОЛ МЕЖДУ ПЛОСКОСТЯМИ (нормали n₁, n₂):
    cos α = |n₁·n₂| / (|n₁|*|n₂|)

  РАССТОЯНИЕ ОТ ТОЧКИ M(x₀,y₀,z₀) ДО ПЛОСКОСТИ Ax+By+Cz+D=0:
    d = |Ax₀ + By₀ + Cz₀ + D| / √(A² + B² + C²)

Шаг 4: Найди нормаль к плоскости через векторное произведение двух векторов в плоскости:
  n = u × v:
    nx = uy*vz - uz*vy
    ny = -(ux*vz - uz*vx)
    nz = ux*vy - uy*vx

Шаг 5: Запиши уравнение плоскости: A(x-x₀) + B(y-y₀) + C(z-z₀) = 0

КЛЮЧЕВЫЕ ФОРМУЛЫ (из справочника Малковой):

--- ВЕКТОРЫ В ПРОСТРАНСТВЕ ---
Координаты: a = AB = (x_B-x_A ; y_B-y_A ; z_B-z_A)
Длина: |a| = √(ax² + ay² + az²)
Сумма: (ax+bx ; ay+by ; az+bz)
λ·a = (λax ; λay ; λaz)
Скалярное произведение: a·b = ax*bx + ay*by + az*bz = |a|*|b|*cos φ
Угол: cos φ = (a·b) / (|a|*|b|)

--- УГЛЫ И РАССТОЯНИЯ (из справочника) ---
Угол между прямыми:    cos φ = |a·b| / (|a|*|b|)
Угол между прямой и плоскостью: sin φ = |a·n| / (|a|*|n|)
Угол между плоскостями: cos φ = |n₁·n₂| / (|n₁|*|n₂|)
Расстояние от точки до плоскости: d = |Ax₀+By₀+Cz₀+D| / √(A²+B²+C²)

Уравнение плоскости: Ax + By + Cz + D = 0
  Нормаль: n = (A, B, C)

--- КОМПЛАНАРНОСТЬ ВЕКТОРОВ ---
Векторы a, b, c компланарны, если c = ma + nb (при некоторых m, n)

--- МЕТОД ОБЪЁМОВ (Малкова) ---
Записываем объём пирамиды двумя способами:
  V = (1/3)*S_ABC*h = (1/3)*S_ABD*d
Из равенства находим h или d (расстояние).
Применяется для: расстояния от точки до плоскости, между скрещивающимися прямыми.

--- РАСПОЛОЖЕНИЕ ПРЯМЫХ В ПРОСТРАНСТВЕ ---
Пересекаются, параллельны, скрещиваются.
Угол между скрещивающимися прямыми: угол между их параллельными переносами через одну точку.

--- ПРИЗНАКИ ---
Прямая ⊥ плоскости: прямая ⊥ двум пересекающимся прямым в плоскости.
Плоскости ∥: две пересекающиеся прямые одной ∥ двум пересекающимся прямым другой.

ТИПИЧНЫЕ ОШИБКИ:

- Неправильно вводят систему координат (рёбра не совпадают с осями).
- Для угла прямой/плоскости — sin, а не cos; для угла плоскостей — cos нормалей.
- Не берут модуль в числителе — получают отрицательный ответ.
- В векторном произведении ошибаются в знаке j-компоненты (там минус!).
- Путают скрещивающиеся и пересекающиеся прямые.

ПРИМЕР 1:
Задача: Куб ABCDA₁B₁C₁D₁, ребро 2. Угол между AC₁ и плоскостью ABCD.
Решение:
A=(0,0,0), C₁=(2,2,2).
Вектор AC₁ = (2,2,2). Нормаль к ABCD: n = (0,0,1).
sin α = |AC₁·n| / (|AC₁|*|n|) = 2 / (2√3 * 1) = 1/√3
α = arcsin(1/√3) ≈ 35°16'
Ответ: arcsin(√3/3) ≈ 35°

ПРИМЕР 2:
Задача: Куб ребра 1. Расстояние от A₁(0,0,1) до плоскости BDC₁.
Решение:
B=(1,0,0), D=(0,1,0), C₁=(1,1,1).
BD = (-1,1,0), BC₁ = (0,1,1).
n = BD × BC₁ = (1*1-0*1 ; -((-1)*1-0*0) ; (-1)*1-1*0) = (1,1,-1)
Плоскость: (x-1) + (y-0) - (z-0) = 0 → x+y-z-1 = 0
d = |0+0-1-1| / √3 = 2/√3 = 2√3/3
Ответ: 2√3/3

ПРИМЕР 3:
Задача: Правильная четырёхугольная пирамида, сторона основания 4, высота 3. Угол боковой грани с основанием.
Решение:
Апофема = расстояние от центра основания до середины стороны = 2.
Апофема пирамиды: m = √(2² + 3²) = √13
tg α = 3/2 → α = arctg(3/2) ≈ 56°19'
Ответ: arctg(3/2) ≈ 56°19'
