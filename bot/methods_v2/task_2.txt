ИСТОЧНИК ФОРМУЛ: Справочник ЕГЭ по математике, Анна Малкова (ege-study.ru)

КЛЮЧЕВЫЕ СЛОВА:
вектор, координаты вектора, длина вектора, модуль вектора, скалярное произведение,
сложение векторов, вычитание векторов, умножение вектора на число,
коллинеарные векторы, перпендикулярные векторы, угол между векторами,
единичный вектор, нулевой вектор, параллельное перенесение,
AB, BC, AC, координатная плоскость, x, y, проекция,
правило треугольника, правило параллелограмма,
найдите угол, найдите длину, найдите скалярное произведение,
вектор через координаты точек, A(x1,y1), B(x2,y2)

ЧТО ПРОВЕРЯЕТСЯ:
Умение выполнять операции с векторами в координатной форме и вычислять угол между векторами через скалярное произведение.

АЛГОРИТМ РЕШЕНИЯ:

Шаг 1: Если даны точки A(x₁,y₁) и B(x₂,y₂) — найди координаты вектора AB:
        AB = (x₂ - x₁ ; y₂ - y₁)

Шаг 2: Если нужны операции — применяй покоординатные правила:
        a + b = (ax + bx ; ay + by)
        a - b = (ax - bx ; ay - by)
        λ * a = (λ*ax ; λ*ay)

Шаг 3: Если нужна длина (модуль):
        |a| = √(ax² + ay²)

Шаг 4: Если нужен угол между векторами:
        Сначала: скалярное произведение a·b = ax*bx + ay*by
        Затем: |a| и |b|
        Потом: cos(φ) = (a·b) / (|a| * |b|)  →  φ = arccos(...)

Шаг 5: Перпендикулярность: a·b = 0.
        Коллинеарность: существует λ, что b = λa (или ax/bx = ay/by)

Шаг 6: Запиши ответ.

КЛЮЧЕВЫЕ ФОРМУЛЫ (из справочника Малковой):

Координаты вектора: AB = (x_B - x_A ; y_B - y_A)
Длина вектора: |a| = √(ax² + ay²)
Скалярное произведение: a·b = ax*bx + ay*by = |a|*|b|*cos(φ)
Угол: cos(φ) = (a·b) / (|a|*|b|)

Сложение: a + b = (ax+bx ; ay+by)
Разность: a - b = (ax-bx ; ay-by)
Произведение на число: λ·a = (λ*ax ; λ*ay)

Перпендикулярность: a⊥b  ⟺  a·b = 0
Коллинеарность: a ∥ b  ⟺  b = λa  ⟺  ax*by = ay*bx

Два способа сложения:
  Правило параллелограмма: начала векторов в одной точке, сумма — диагональ.
  Правило треугольника: конец первого = начало второго, сумма — замыкающий вектор.

Равные векторы: одинаковая длина и одинаковое направление.
  Вектор можно переносить параллельно себе в любую точку.

ТИПИЧНЫЕ ОШИБКИ:

- При вычислении вектора AB путают порядок: нужно B - A (конец минус начало), а не A - B.
- Забывают взять квадратный корень при вычислении длины вектора.
- Путают скалярное произведение (число) с операцией типа «покоординатное умножение».
- Угол между векторами от 0° до 180°. Если cos < 0 — угол тупой, это нормально.
- Коллинеарность путают с перпендикулярностью.

ПРИМЕР 1:
Задача: Даны векторы a = (3 ; 4) и b = (1 ; -2). Найдите скалярное произведение a·b и длину вектора a.
Решение:
a·b = 3*1 + 4*(-2) = 3 - 8 = -5
|a| = √(9 + 16) = √25 = 5
Ответ: a·b = -5, |a| = 5

ПРИМЕР 2:
Задача: Найдите угол между векторами a = (1 ; √3) и b = (√3 ; 1).
Решение:
Шаг 1: a·b = 1*√3 + √3*1 = 2√3
Шаг 2: |a| = √(1+3) = 2, |b| = √(3+1) = 2
Шаг 3: cos(φ) = 2√3 / (2*2) = √3/2
Шаг 4: φ = 30°
Ответ: 30°

ПРИМЕР 3:
Задача: Даны точки A(1; 2), B(4; 6), C(0; 5). Найдите AB + AC и длину этого вектора.
Решение:
AB = (4-1 ; 6-2) = (3 ; 4)
AC = (0-1 ; 5-2) = (-1 ; 3)
AB + AC = (2 ; 7)
|AB + AC| = √(4 + 49) = √53
Ответ: вектор (2; 7), длина √53 ≈ 7,28
