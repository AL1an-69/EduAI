ЗАДАНИЕ 6 — ПРОСТЕЙШИЕ УРАВНЕНИЯ

ИСТОЧНИК ФОРМУЛ: Справочник ЕГЭ по математике, Анна Малкова (ege-study.ru)

КЛЮЧЕВЫЕ СЛОВА:
уравнение, решите уравнение, найдите корень, линейное уравнение,
квадратное уравнение, дискриминант, теорема Виета, разложение на множители,
дробное уравнение, иррациональное уравнение, уравнение с корнем,
модуль, уравнение с модулем, |x| = a,
ОДЗ, область допустимых значений, знаменатель не равен нулю,
2x + 3 = 7, ax² + bx + c = 0, x², корень из x

ЧТО ПРОВЕРЯЕТСЯ:
Умение решать линейные, квадратные и простейшие нелинейные уравнения, включая уравнения с модулем и корнями.

АЛГОРИТМ РЕШЕНИЯ:

-- ЛИНЕЙНОЕ УРАВНЕНИЕ (ax + b = c) --
Шаг 1: Перенеси слагаемые с x в левую часть, числа — в правую.
Шаг 2: Приведи подобные.
Шаг 3: Раздели на коэффициент при x.

-- КВАДРАТНОЕ УРАВНЕНИЕ (ax² + bx + c = 0) --
Шаг 1: Вычисли D = b² - 4ac
Шаг 2: D > 0 → два корня: x = (-b ± √D) / (2a)
        D = 0 → один корень: x = -b / (2a)
        D < 0 → нет действительных корней
Шаг 3: Проверь через теорему Виета: x₁+x₂ = -b/a, x₁*x₂ = c/a

-- УРАВНЕНИЕ С МОДУЛЕМ (|f(x)| = g(x)) --
Шаг 1: Условие: g(x) ≥ 0
Шаг 2: Раскрой: f(x) = g(x)  ИЛИ  f(x) = -g(x)
Шаг 3: Реши оба. Проверь корни.

-- УРАВНЕНИЕ С КОРНЕМ (√f(x) = g(x)) --
Шаг 1: ОДЗ: f(x) ≥ 0 и g(x) ≥ 0
Шаг 2: Возведи в квадрат: f(x) = g(x)²
Шаг 3: Реши. Проверь в исходном.

-- ДРОБНОЕ УРАВНЕНИЕ --
Шаг 1: ОДЗ: все знаменатели ≠ 0
Шаг 2: Умножь на общий знаменатель
Шаг 3: Реши, исключи решения вне ОДЗ

КЛЮЧЕВЫЕ ФОРМУЛЫ (из справочника Малковой):

Квадратное уравнение ax² + bx + c = 0:
  D = b² - 4ac
  При D > 0: x₁ = (-b - √D) / (2a),  x₂ = (-b + √D) / (2a)
  При D = 0: x = -b / (2a)

Теорема Виета (для ax² + bx + c = 0):
  x₁ + x₂ = -b/a
  x₁ * x₂ = c/a

Разложение квадратного трёхчлена:
  ax² + bx + c = a * (x - x₁) * (x - x₂)

Координаты вершины параболы y = ax² + bx + c:
  x₀ = -b / (2a)
  y₀ = y(x₀)

Модуль числа:
  |x| = x, если x ≥ 0
  |x| = -x, если x < 0
  |x| ≥ 0 всегда
  √(x²) = |x|

ТИПИЧНЫЕ ОШИБКИ:

- Не меняют знаки всех членов при раскрытии скобок со знаком «минус».
- В формуле дискриминанта пишут b - 4ac вместо b² - 4ac.
- При иррациональных уравнениях не проверяют корни (посторонние).
- В дробных уравнениях не проверяют ОДЗ — оставляют корень при котором знаменатель = 0.
- При уравнении с модулем забывают второй случай (f(x) = -g(x)).

ПРИМЕР 1:
Задача: Решите уравнение 3x² - 5x - 2 = 0.
Решение:
D = 25 + 24 = 49, √D = 7
x₁ = (5 - 7) / 6 = -1/3
x₂ = (5 + 7) / 6 = 2
Ответ: x = -1/3, x = 2

ПРИМЕР 2:
Задача: Решите уравнение |2x - 3| = 5.
Решение:
2x - 3 = 5  →  x = 4
2x - 3 = -5  →  x = -1
Ответ: x = 4, x = -1

ПРИМЕР 3:
Задача: Решите уравнение √(2x - 1) = x - 2.
Решение:
ОДЗ: 2x-1 ≥ 0 и x-2 ≥ 0 → x ≥ 2
Возводим в квадрат: 2x-1 = (x-2)² = x²-4x+4
x² - 6x + 5 = 0, D = 36-20 = 16, x = (6±4)/2: x₁=5, x₂=1
Проверка ОДЗ: x=5 ✓, x=1 — не входит (1 < 2)
Ответ: x = 5
