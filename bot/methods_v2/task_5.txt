ЧТО ПРОВЕРЯЕТСЯ:
Умение вычислять вероятности сложных событий: формула Бернулли, условная вероятность, математическое ожидание.

АЛГОРИТМ РЕШЕНИЯ:

-- ФОРМУЛА БЕРНУЛЛИ (ровно k успехов из n испытаний) --
Шаг 1: Определи n, k, p (вероятность успеха в одном испытании).
Шаг 2: q = 1 - p
Шаг 3: P(n,k) = C(n,k) * p^k * q^(n-k)
Шаг 4: C(n,k) = n! / (k! * (n-k)!)

-- УСЛОВНАЯ ВЕРОЯТНОСТЬ --
Шаг 1: Нарисуй «дерево» возможных исходов с ветками и вероятностями.
Шаг 2: p(AB) = p(B) * p(A|B) — вероятность пути по дереву
Шаг 3: p(A|B) = p(AB) / p(B)

-- МАТЕМАТИЧЕСКОЕ ОЖИДАНИЕ --
M = x₁*p₁ + x₂*p₂ + ... + xₙ*pₙ
(сумма произведений значений на их вероятности)

-- ХОТЯ БЫ ОДНО из n независимых событий --
P = 1 - P(ни одного) = 1 - (1-p)^n

КЛЮЧЕВЫЕ ФОРМУЛЫ (из справочника Малковой):

Формула Бернулли: P(n,k) = C(n,k) * p^k * q^(n-k)
  p — вероятность успеха в одном испытании
  q = 1 - p — вероятность неудачи
  C(n,k) = n! / (k! * (n-k)!)
  n! = 1 * 2 * 3 * ... * n  (факториал)
  По определению: 0! = 1

Условная вероятность: p(A|B) = p(AB) / p(B)

Математическое ожидание: M = x₁*p₁ + x₂*p₂ + ... + xₙ*pₙ

Среднее арифметическое = сумма чисел / их количество
Медиана — число ровно посередине упорядоченной последовательности
Мода — число, встречающееся чаще других

ПРИМЕР из справочника (Малкова) — математическое ожидание:
Беспроигрышная лотерея. Билеты: 990 штук по 10 руб., 6 по 50 руб., 3 по 100 руб., 1 по 5000 руб. Всего 1000 билетов.
M = 10 * 0,99 + 50 * 0,006 + 100 * 0,003 + 5000 * 0,001 = 9,9 + 0,3 + 0,3 + 5 = 15,5 руб.

ТИПИЧНЫЕ ОШИБКИ:

- Путают «ровно k» с «хотя бы k» — это разные события.
- Забывают q = 1 - p и берут p вместо q или наоборот.
- Ошибаются в подсчёте C(n,k), путая факториалы.
- При условной вероятности не строят дерево — теряют ветки.
- В математическом ожидании суммируют только значения (без умножения на вероятность).

ПРИМЕР 1:
Задача: Монету бросают 4 раза. Вероятность орла при одном броске = 0,5. Найдите вероятность ровно 3 орлов.
Решение:
n = 4, k = 3, p = 0,5, q = 0,5
C(4,3) = 4! / (3! * 1!) = 4
P = 4 * (0,5)³ * (0,5)¹ = 4 * 0,125 * 0,5 = 0,25
Ответ: 0,25

ПРИМЕР 2 (условная вероятность — пример Малковой):
Задача: Тест на болезнь положителен в 86% у больных и в 6% у здоровых. Вероятность болезни 0,05. Пациент сдал тест — положительный. Найдите вероятность, что болен.
Решение:
p(B) = 0,05 * 0,86 + 0,95 * 0,06 = 0,043 + 0,057 = 0,1
p(болен и тест+) = 0,05 * 0,86 = 0,043
p(болен | тест+) = 0,043 / 0,1 = 0,43
Ответ: 0,43

ПРИМЕР 3:
Задача: В таблице для лотереи: 990 билетов по 10 руб., 6 по 50 руб., 3 по 100 руб., 1 по 5000 руб. Всего 1000. Цена билета 50 руб. На сколько цена выше матожидания?
Решение:
M = 10*0,99 + 50*0,006 + 100*0,003 + 5000*0,001 = 15,5 руб.
Разница: 50 - 15,5 = 34,5 руб.
Ответ: 34,5
