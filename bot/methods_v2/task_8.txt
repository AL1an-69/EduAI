ЗАДАНИЕ 8 — ПРОИЗВОДНАЯ И ПЕРВООБРАЗНАЯ

ИСТОЧНИК ФОРМУЛ: Справочник ЕГЭ по математике, Анна Малкова (ege-study.ru)

КЛЮЧЕВЫЕ СЛОВА:
производная, дифференцирование, f'(x), таблица производных,
первообразная, интеграл, F(x), таблица первообразных, Newton-Leibniz,
точка максимума, точка минимума, точка перегиба, экстремум, критическая точка,
возрастание, убывание, монотонность, f'(x) > 0, f'(x) < 0,
касательная к графику, угловой коэффициент, уравнение касательной,
производная суммы, произведения, частного, сложной функции,
площадь криволинейной трапеции, формула Ньютона-Лейбница

ЧТО ПРОВЕРЯЕТСЯ:
Умение находить производные и первообразные функций, применять производную для исследования функции, находить площади.

АЛГОРИТМ РЕШЕНИЯ:

-- НАХОЖДЕНИЕ ПРОИЗВОДНОЙ --
Шаг 1: Определи тип функции.
Шаг 2: Применяй таблицу производных и правила.
Шаг 3: Для сложной функции: (f(g(x)))' = f'(g(x)) * g'(x)

-- ТОЧКИ ЭКСТРЕМУМА --
Шаг 1: f'(x) = 0 → найди критические точки.
Шаг 2: Определи знак f'(x) слева и справа:
  «+» → «−»: максимум
  «−» → «+»: минимум
  знак не меняется: не экстремум

-- УРАВНЕНИЕ КАСАТЕЛЬНОЙ в точке x₀ --
Шаг 1: y₀ = f(x₀)
Шаг 2: k = f'(x₀)
Шаг 3: Уравнение: y = k*(x - x₀) + y₀

-- ПЕРВООБРАЗНАЯ И ПЛОЩАДЬ --
F(x) — первообразная, если F'(x) = f(x)
Площадь криволинейной трапеции (y ≥ 0 на [a; b]):
  S = F(b) - F(a)   [формула Ньютона-Лейбница]

КЛЮЧЕВЫЕ ФОРМУЛЫ (из справочника Малковой):

--- ТАБЛИЦА ПРОИЗВОДНЫХ ---
(C)' = 0
(x)' = 1
(x²)' = 2x
(xⁿ)' = n * xⁿ⁻¹
(√x)' = 1 / (2√x)
(1/x)' = -1/x²
(sin x)' = cos x
(cos x)' = -sin x
(tg x)' = 1 / cos²x
(ctg x)' = -1 / sin²x
(eˣ)' = eˣ
(aˣ)' = aˣ * ln(a)
(ln x)' = 1/x
(log_a x)' = 1 / (x * ln a)

--- ПРАВИЛА ДИФФЕРЕНЦИРОВАНИЯ ---
(u + v)' = u' + v'
(u - v)' = u' - v'
(u * v)' = u'*v + u*v'
(u / v)' = (u'*v - u*v') / v²
(c * f)' = c * f'
Сложная функция: (f(g(x)))' = f'(g(x)) * g'(x)

--- ТАБЛИЦА ПЕРВООБРАЗНЫХ ---
0 → C
1 → x + C
x → x²/2 + C
xⁿ → x^(n+1)/(n+1) + C  (n ≠ -1)
1/x → ln|x| + C
sin x → -cos x + C
cos x → sin x + C
eˣ → eˣ + C

Исследование функции через производную:
  f'(x) > 0 → функция возрастает
  f'(x) < 0 → функция убывает
  В точке максимума: f'(x) = 0, знак меняется «+» → «−»
  В точке минимума: f'(x) = 0, знак меняется «−» → «+»
  Точка перегиба: f'(x) = 0, знак НЕ меняется

ТИПИЧНЫЕ ОШИБКИ:

- Для сложной функции не применяют цепное правило: (sin(3x))' = cos(3x)*3, а не cos(3x).
- Путают производную и первообразную: производная понижает степень, первообразная — повышает.
- В точках экстремума не проверяют смену знака производной.
- Забывают константу C при нахождении первообразной.
- В производной частного (u'v - uv')/v², не (uv' - u'v).

ПРИМЕР 1:
Задача: Найдите производную f(x) = 3x⁴ - 2x² + 5x - 1.
Решение:
f'(x) = 12x³ - 4x + 5
Ответ: f'(x) = 12x³ - 4x + 5

ПРИМЕР 2:
Задача: Найдите производную f(x) = sin(2x² + 1).
Решение:
Сложная функция: f'(x) = cos(2x² + 1) * (2x² + 1)' = cos(2x² + 1) * 4x
Ответ: f'(x) = 4x * cos(2x² + 1)

ПРИМЕР 3:
Задача: Найдите точки экстремума f(x) = x³ - 3x² - 9x + 5.
Решение:
f'(x) = 3x² - 6x - 9 = 3(x² - 2x - 3) = 3(x-3)(x+1) = 0
Критические точки: x = -1, x = 3
Знак f'(x):
  x < -1: f'(x) > 0
  -1 < x < 3: f'(x) < 0
  x > 3: f'(x) > 0
x = -1: максимум, f(-1) = -1 - 3 + 9 + 5 = 10
x = 3: минимум, f(3) = 27 - 27 - 27 + 5 = -22
Ответ: максимум 10 при x = -1; минимум -22 при x = 3
