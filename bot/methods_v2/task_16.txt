ИСТОЧНИК ФОРМУЛ: Справочник ЕГЭ по математике, Анна Малкова (ege-study.ru)

КЛЮЧЕВЫЕ СЛОВА:
вклад, депозит, кредит, ипотека, процентная ставка, годовых,

ЧТО ПРОВЕРЯЕТСЯ:
Умение применять формулы начисления процентов и вычислять параметры кредита/вклада.

АЛГОРИТМ РЕШЕНИЯ:

-- ВКЛАД (ПРОСТЫЕ ПРОЦЕНТЫ) --
S = P * (1 + r*n)
P — начальная сумма, r — ставка в долях, n — число периодов

-- ВКЛАД (СЛОЖНЫЕ ПРОЦЕНТЫ) --
S = P * k^n, где k = 1 + p/100
n — число периодов

-- СХЕМА 1: КРЕДИТ, ПОГАШЕНИЕ РАВНЫМИ ПЛАТЕЖАМИ (АННУИТЕТ) --
По схеме из справочника Малковой:
  (((S*k - X)*k - X)*k - X) * ... = 0
  S — сумма кредита, k = 1 + p/100, X — ежегодный платёж, n платежей.
  Раскрывая скобки и применяя сумму геом. прогрессии:
  X = S * k^n / (k^(n-1) + k^(n-2) + ... + 1) = S * k^n * (k-1) / (k^n - 1)
  Переплата = X*n - S

-- СХЕМА 2: КРЕДИТ, РАВНОМЕРНОЕ УМЕНЬШЕНИЕ ДОЛГА (ДИФФЕРЕНЦИРОВАННЫЕ) --
Каждый период погашается S/n основного долга + проценты на остаток.
1-я выплата: Z₁ = S*k^(n-1) - S/n * (k^(n-1) + ... + k) ... (схема из справочника)
Общая переплата: П = S * (n+1)/2 * p/100

КЛЮЧЕВЫЕ ФОРМУЛЫ (из справочника Малковой):

Коэффициент наращения: k = 1 + p/100

Схема 1 (равные платежи):
  Уравнение: S*k^n - X*(k^n-1)/(k-1) = 0
  Платёж: X = S*k^n*(k-1) / (k^n - 1)

Схема 2 (дифференцированные):
  Переплата: П = S * (n+1)/2 * p/100
  Общая выплата: Z = S + П

Пример из справочника Малковой:
  Кредит S = 364 000 руб., p = 20%, k = 1,2, n = 3 года (равные платежи).
  X = 364000 * 1,2³ / (1,2² + 1,2 + 1) = 364000 * 1,728 / 3,64 = 172 800 руб.

ТИПИЧНЫЕ ОШИБКИ:

- Путают ставку в % и в долях: p = 20% → r = 0,20 (делить на 100).
- Простые проценты: S = P*(1+rn), а не S = P*(1+r)^n (это сложные).
- При ежемесячном начислении годовую ставку не делят на 12.
- При аннуитете: n лет при ежемесячных платежах → n*12 периодов.
- В схеме с дифференцированными платежами берут неправильную формулу переплаты.

ПРИМЕР 1:
Задача: Вклад 50 000 руб. под 8% годовых (сложные проценты) на 3 года.
Решение:
k = 1,08, S = 50000 * 1,08³ = 50000 * 1,259712 ≈ 62 985,60 руб.
Ответ: ≈ 62 986 руб.

ПРИМЕР 2 (из справочника Малковой):
Задача: Маша берёт 364 000 руб. под 20% годовых. Выплата 3 равными ежегодными платежами. Найти размер платежа.
Решение:
k = 1,2, n = 3
X = 364000 * 1,2³ / (1,2² + 1,2 + 1) = 364000 * 1,728 / 3,64 = 172 800 руб.
Ответ: 172 800 руб.

ПРИМЕР 3:
Задача: Кредит 300 000 руб. на 2 года под 12% годовых (ежемесячные равные выплаты). Ежемесячный платёж и переплата.
Решение:
r = 0,12/12 = 0,01, n = 24, k = 1,01
X = 300000 * 1,01²⁴ * 0,01 / (1,01²⁴ - 1)
1,01²⁴ ≈ 1,2697
X = 300000 * 1,2697 * 0,01 / 0,2697 ≈ 14 124 руб.
Переплата = 14124 * 24 - 300000 ≈ 38 976 руб.
Ответ: ≈ 14 124 руб./мес., переплата ≈ 38 976 руб.
