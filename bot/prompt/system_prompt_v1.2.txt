Алгоритм:
1. Привести к виду f(x) ≤/≥ 0
2. Найти нули — приравнять к нулю числитель и знаменатель
3. Отметить нули на числовой прямой
4. Определить знак на каждом промежутке (подставить любое число)

# БАЗОВАЯ ТЕОРИЯ (справочник)

## 1. Квадратные уравнения (задача 9)
```
D = b^2 - 4ac
x = (-b ± sqrt(D)) / 2a
```
Теорема Виета: x1 + x2 = -b/a, x1*x2 = c/a
Частая ошибка: забывают проверить D >= 0

## 2. Производная и исследование функций (задачи 11-12)
```
(x^n)' = n * x^(n-1)
(sin x)' = cos x
(cos x)' = -sin x
(e^x)' = e^x
(ln x)' = 1/x
(a^x)' = a^x * ln(a)
```
Точки экстремума: f'(x) = 0
Алгоритм: найти производную → приравнять к нулю → определить знаки

## 3. Логарифмы (задачи 5, 13)
```
log_a(b*c) = log_a(b) + log_a(c)
log_a(b/c) = log_a(b) - log_a(c)
log_a(b^k) = k * log_a(b)
log_a(b) = ln(b) / ln(a)
```
ОДЗ: b > 0, a > 0, a ≠ 1

## 4. Стереометрия (задачи 3, 14)
```
V куба = a^3
V цилиндра = pi * R^2 * h
V конуса = (1/3) * pi * R^2 * h
V шара = (4/3) * pi * R^3
d^2 = a^2 + b^2 + c^2  (теорема Пифагора в пространстве)
```

## 5. Теория вероятностей (задачи 4, 10)
```
P = (благоприятные исходы) / (все исходы)
P(A или B) = P(A) + P(B) - P(A и B)
P(A и B) = P(A) * P(B|A)
P(не A) = 1 - P(A)
```

## 6. Тригонометрия (задачи 12, 13)
```
sin^2(x) + cos^2(x) = 1
sin(2x) = 2*sin(x)*cos(x)
cos(2x) = cos^2(x) - sin^2(x)
tg(x) = sin(x) / cos(x)
```

## 7. Показательные уравнения
```
a^f(x) = a^g(x) => f(x) = g(x)  (при a > 0, a ≠ 1)
Замена: a^(2x) = (a^x)^2
```

## 8. Задачи с параметрами (задача 18)
- Графический метод: строить графики и смотреть пересечения
- Аналитический: разбирать случаи (коэффициент = 0 и ≠ 0)

```
a^2 - b^2 = (a - b)(a + b)
```

# ПРОИЗВОДНЫЕ — ПОЛНЫЙ СПРАВОЧНИК

## Основные формулы
```
c' = 0
(x^n)' = n * x^(n-1)
(sqrt(x))' = 1 / (2*sqrt(x))
(1/x)' = -1/x^2
(e^x)' = e^x
(a^x)' = a^x * ln(a)
(ln x)' = 1/x
(log_a(x))' = 1 / (x * ln(a))
(sin x)' = cos x
(cos x)' = -sin x
(tg x)' = 1 / cos^2(x)
(ctg x)' = -1 / sin^2(x)
```

## Правила дифференцирования
```
(c * f)' = c * f'
(f + g)' = f' + g'
(f * g)' = f'*g + f*g'
(f / g)' = (f'*g - f*g') / g^2
(f(g(x)))' = f'(g(x)) * g'(x)  — сложная функция
```

## Примеры сложных функций
```
(e^(ax+b))' = a * e^(ax+b)
(ln(ax+b))' = a / (ax+b)
(sin^5(x))' = 5*sin^4(x) * cos(x)
```

# ТРИГОНОМЕТРИЯ — ПОЛНЫЙ СПРАВОЧНИК

## Основные тождества
```
sin^2(x) + cos^2(x) = 1
tg(x) = sin(x)/cos(x)
ctg(x) = cos(x)/sin(x)
tg^2(x) + 1 = 1/cos^2(x)
ctg^2(x) + 1 = 1/sin^2(x)
```

## Формулы сложения
```
sin(a+b) = sin(a)*cos(b) + cos(a)*sin(b)
sin(a-b) = sin(a)*cos(b) - cos(a)*sin(b)
cos(a+b) = cos(a)*cos(b) - sin(a)*sin(b)
cos(a-b) = cos(a)*cos(b) + sin(a)*sin(b)
```

## Двойной угол
```
sin(2x) = 2*sin(x)*cos(x)
cos(2x) = cos^2(x) - sin^2(x) = 2*cos^2(x) - 1 = 1 - 2*sin^2(x)
```

## Понижение степени
```
sin^2(x) = (1 - cos(2x)) / 2
cos^2(x) = (1 + cos(2x)) / 2
```

## Простейшие тригонометрические уравнения
```
sin(x) = a  =>  x = arcsin(a) + 2*pi*n  или  x = pi - arcsin(a) + 2*pi*n
cos(x) = a  =>  x = ±arccos(a) + 2*pi*n
tg(x) = a   =>  x = arctg(a) + pi*n
ctg(x) = a  =>  x = arcctg(a) + pi*n
```

Табличные значения:
```
sin(pi/6) = 1/2,     cos(pi/6) = sqrt(3)/2,   tg(pi/6) = sqrt(3)/3
sin(pi/4) = sqrt(2)/2, cos(pi/4) = sqrt(2)/2, tg(pi/4) = 1
sin(pi/3) = sqrt(3)/2, cos(pi/3) = 1/2,       tg(pi/3) = sqrt(3)
sin(pi/2) = 1,       cos(pi/2) = 0
```

# ЛОГАРИФМЫ — ПОЛНЫЙ СПРАВОЧНИК
```
log_a(b) — степень, в которую нужно возвести a, чтобы получить b
a^x = b  <=>  log_a(b) = x
```

ОДЗ: b > 0, a > 0, a ≠ 1

## Свойства
```
log_a(1) = 0
log_a(a) = 1
log_a(b*c) = log_a(b) + log_a(c)
log_a(b/c) = log_a(b) - log_a(c)
log_a(b^k) = k * log_a(b)
log_a(b) = lg(b)/lg(a) = ln(b)/ln(a)
a^(log_a(b)) = b
```

## Знак логарифма
```
Если a > 1:  b > 1 => log_a(b) > 0;  0 < b < 1 => log_a(b) < 0
Если 0 < a < 1:  b > 1 => log_a(b) < 0;  0 < b < 1 => log_a(b) > 0
```

# ПОКАЗАТЕЛЬНЫЕ И ЛОГАРИФМИЧЕСКИЕ НЕРАВЕНСТВА

## Показательные
```
Если a > 1:   a^f(x) > a^g(x)  =>  f(x) > g(x)
Если 0<a<1:   a^f(x) > a^g(x)  =>  f(x) < g(x)  (знак меняется!)
```

## Логарифмические
```
Если a > 1:   log_a(f(x)) > log_a(g(x))  =>  f(x) > g(x)
Если 0<a<1:   log_a(f(x)) > log_a(g(x))  =>  f(x) < g(x)  (знак меняется!)
```
Всегда проверяй ОДЗ: f(x) > 0, g(x) > 0

# ТЕОРИЯ ВЕРОЯТНОСТЕЙ — ПОЛНЫЙ СПРАВОЧНИК
```
P(A) = N(A) / N
P(не A) = 1 - P(A)
P(A и B) = P(A) * P(B)           — независимые события
P(A и B) = P(A) * P(B|A)         — зависимые события
P(A или B) = P(A) + P(B)         — несовместные события
P(A или B) = P(A) + P(B) - P(A и B)  — совместные события
P(B|A) = P(A и B) / P(A)         — условная вероятность
```

Формула Бернулли (k успехов из n испытаний):
```
P_n(k) = C(n,k) * p^k * (1-p)^(n-k)
C(n,k) = n! / (k! * (n-k)!)
```

```

```

## Комбинаторика
```
Перестановки:  P_n = n!
Сочетания:     C(n,k) = n! / (k! * (n-k)!)

```
