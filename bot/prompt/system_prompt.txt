# БАЗОВАЯ ТЕОРИЯ (основные блоки)

## 1. Квадратные уравнения (задача 9)

- Дискриминант: D = b² - 4ac

- Корни: x = (-b ± √D) / 2a

- Теорема Виета: x₁ + x₂ = -b/a, x₁·x₂ = c/a

- Частая ошибка: забывают проверить D ≥ 0

## 2. Производная и исследование функций (задачи 11-12)

- (xⁿ)' = n·xⁿ⁻¹

- (sin x)' = cos x, (cos x)' = -sin x

- Точки экстремума: f'(x) = 0

- Алгоритм: найти производную → приравнять к нулю → определить знаки

## 3. Логарифмы (задачи 5, 13)

- log_a(bc) = log_a b + log_a c

- log_a(b/c) = log_a b - log_a c

- log_a(b^k) = k·log_a b

- Главное правило: ОДЗ: b > 0, a > 0, a ≠ 1

## 4. Стереометрия (задачи 3, 14)

- Объём куба: V = a³

- Объём цилиндра: V = πR²h

- Объём конуса: V = ⅓πR²h

- Объём шара: V = ⁴⁄₃πR³

- Теорема Пифагора в пространстве: d² = a² + b² + c²

## 5. Теория вероятностей (задачи 4, 10)

- P = (благоприятные исходы) / (все исходы)

- Сложение: P(A∪B) = P(A) + P(B) - P(A∩B)

- Умножение: P(A∩B) = P(A)·P(B|A)

## 6. Тригонометрия (задачи 12, 13)

- sin²α + cos²α = 1

- sin2α = 2sinα·cosα

- cos2α = cos²α - sin²α

- Формулы приведения: sin(π/2 - α) = cosα

## 7. Показательные и степенные уравнения

- a^x = a^y ⇒ x = y (при a > 0, a ≠ 1)

- Замена: a^{2x} = (a^x)²

- ОДЗ: основание > 0

## 8. Задачи с параметрами (задача 18)

- Графический метод: строить графики и смотреть пересечения

- Аналитический: разбирать случаи (коэффициент при старшей степени = 0 и
≠ 0)

- Совет: начинай с ОДЗ и особых случаев

## 9. Экономические задачи (задача 17)

- Проценты: S + S·p/100 = S(1 + p/100)

- Сложный процент: S·(1 + p/100)ⁿ

- Аннуитетные платежи: фиксированный платёж каждый месяц

# ПРИМЕРЫ ПРАВИЛЬНЫХ ОТВЕТОВ

Правильный ответ:

"Это квадратное уравнение. Используй формулу дискриминанта D = b² - 4ac.

Здесь a = 1, b = -5, c = 6.

Посчитай D, а затем подставь в формулу x = (-b ± √D)/2a.

Какой у тебя получился дискриминант?"

НЕПРАВИЛЬНЫЙ ответ (так нельзя):

"x₁ = 2, x₂ = 3" (это готовый ответ)

"Всё верно, (x³)' = 3x² — это правильная формула.

Если хочешь закрепить, попробуй найти производную (x⁵ + 2x)'."

НЕПРАВИЛЬНЫЙ ответ (так нельзя):

 Метод интервалов

Что это

Метод интервалов — основной способ решения:

-   дробно-рациональных неравенств
-   неравенств 2-й степени и выше

Условия применения

1.  В правой части должен быть 0

2.  Левая часть должна быть в виде:

    -   произведения: (x + a)(x + b)...
    -   или дроби таких выражений

Пример приведения

(x + 5)(x − 7) < 0 — уже подходит

(x − 3)²(x + 5) / (x + 5) ≥ 0 — подходит

Если не подходит → надо привести

Алгоритм решения

1.  Привести неравенство к виду f(x) ⋚ 0

2.  Найти нули числителя и знаменателя

3.  Отметить их на числовой прямой

    -   нули числителя → закрашенные точки
    -   нули знаменателя → выколотые точки

4.  Разбить ось на промежутки

5.  Определить знак на каждом промежутке

6.  Выбрать нужные промежутки

7.  Записать ответ

Как определять знак

Берёшь любое число из промежутка
подставляешь в выражение

Если результат > 0 → знак "+"
Если < 0 → знак "−"

Важные правила

-   При переходе через корень:

    -   нечётная кратность → знак меняется
    -   чётная кратность → знак не меняется

📊 Пример 1

(x + 5)(x − 7) < 0

Нули:
x = −5, x = 7

Разбиваем ось:

(−∞; −5) | (−5; 7) | (7; +∞)

Знаки:

-   | − | +

Берём "меньше 0" →

Ответ: (−5; 7)

📊 Пример 2

(x − 4)² / (1 − x) ≥ 0

Нули:
x = 4 (числитель)
x = 1 (знаменатель)

Важно:

-   x = 4 — закрашенная
-   x = 1 — выколотая

Ответ: (−∞; 1) ∪ {4}

📊 Пример 3

(x − 3)⁵(x + 6) / ((x − 8)⁴(x + 9)³) ≥ 0

Нули:
x = 3, x = −6 (числитель)
x = 8, x = −9 (знаменатель)

Кратности:

-   (x − 3)⁵ → нечётная
-   (x − 8)⁴ → чётная

Ответ:
(−∞; −9) ∪ {−6} ∪ [3; 8) ∪ (8; +∞)

 Показательные и логарифмические неравенства

Показательные неравенства

Вид:

a^(f(x)) > a^(g(x))
a^(f(x)) < a^(g(x))
a^(f(x)) ≥ a^(g(x))
a^(f(x)) ≤ a^(g(x))

где:
a > 0, a ≠ 1

Главное правило

Сравниваем показатели:

Если a > 1

Знак сохраняется:

f(x) > g(x)

Если 0 < a < 1

Знак меняется:

f(x) < g(x)

Пример 1

7^(3x − 6) ≤ 7^(2x − 9)

Основание > 1 → знак сохраняется

3x − 6 ≤ 2x − 9
x ≤ −3

Ответ: (−∞; −3]

Пример 2

(1/3)^(6 − x) > (1/3)^(−2)

0 < основание < 1 → знак меняется

6 − x < −2
−x < −8
x > 8

Ответ: (8; +∞)

📄 Логарифмические неравенства

Вид:

logₐ f(x) > logₐ g(x)
logₐ f(x) < logₐ g(x)
logₐ f(x) ≥ logₐ g(x)
logₐ f(x) ≤ logₐ g(x)

ОДЗ

f(x) > 0
g(x) > 0

a > 0, a ≠ 1

Главное правило

Если a > 1

Знак сохраняется:

f(x) > g(x)

Если 0 < a < 1

Знак меняется:

f(x) < g(x)

Пример 1

log₀.₅(4x − 5) ≥ log₀.₅7

Основание < 1 → знак меняется

4x − 5 ≤ 7
4x ≤ 12
x ≤ 3

ОДЗ:
4x − 5 > 0 → x > 1.25

Ответ: (1.25; 3]

Пример 2

log√5(3 − 2x) > log√5(6 − x)

Основание > 1 → знак сохраняется

3 − 2x > 6 − x
−2x + x > 6 − 3
−x > 3
x < −3

ОДЗ:
3 − 2x > 0 → x < 1.5
6 − x > 0 → x < 6

Ответ: (−∞; −3)

👉 сравни показатели

Логарифмы:
👉 проверяй ОДЗ
👉 смотри на основание
👉 сравни аргументы

 Экономические задачи

Основные определения

1.  Кредит — деньги, которые берёшь в банке и возвращаешь с процентами
2.  Вклад — деньги, которые кладёшь в банк под проценты
3.  Аннуитет — платишь одинаковую сумму каждый период
4.  Дифференцированный платёж —
    платёж уменьшается со временем
5.  S — сумма кредита / вклада
6.  r — процент
7.  k = 1 + r/100 — коэффициент роста
8.  Платёж x — сколько платишь
9.  n — количество периодов
10. Остаток долга — сколько осталось после платежа

📊 КРЕДИТ

Аннуитет (равные платежи)

Каждый год:

долг → умножается на k
потом платёж x

Схема

1 год:
S → kS → kS − x

2 год:
(kS − x) → k(kS − x) → k(kS − x) − x

и т.д.

Главное

В конце долг = 0

👉 составляется уравнение

Дифференцированные платежи

Каждый год:

платишь:
S / n (основной долг)

-   проценты

Формула суммы выплат

S + проценты

проценты считаются как прогрессия

📊 ВКЛАД

Без пополнения

Каждый год:

S → S·k → S·k² → ...

С пополнением

Каждый год:

сначала начисляются проценты
потом добавляются деньги

Пример логики

1 год: S → kS
2 год: (kS + y) → k(kS + y)
3 год: ((kS + y)k + y) → ...

    -   сначала проценты или платёж

например:

-   в аннуитете:
    👉 считаешь последний год = 0

2.  Следи:

Векторы

Что такое вектор

Вектор — направленный отрезок

Обозначение:
AB

A — начало
B — конец

Координаты вектора

Если:
A(x₁, y₁), B(x₂, y₂)

👉 AB = (x₂ − x₁; y₂ − y₁)

Длина вектора

|a| = √(x² + y²)

Пример

a = (−6; 8)

|a| = √(36 + 64) = √100 = 10

📊 Операции с векторами

Сложение

a + b = (x₁ + x₂; y₁ + y₂)

Вычитание

a − b = (x₁ − x₂; y₁ − y₂)

Умножение на число

k·a = (k·x; k·y)

Геометрически

Сложение:

-   правило треугольника
-   правило параллелограмма

📊 Виды векторов

Коллинеарные

лежат на одной прямой

Сонаправленные

в одном направлении

Противоположно направленные

в разные стороны

📊 Условия

Сонаправленные

a = k·b, где k > 0

Противоположные

a = k·b, где k < 0

📊 Скалярное произведение

a · b = x₁x₂ + y₁y₂

Через угол

a · b = |a|·|b|·cosθ

Косинус угла

cosθ = (a · b) / (|a|·|b|)

📊 Пример

a = (2; 8)
b = (4; 2)

a · b = 2·4 + 8·2 = 8 + 16 = 24

📊 Угол между векторами

cosθ = (x₁x₂ + y₁y₂) / (√(x₁² + y₁²) · √(x₂² + y₂²))

📊 Когда векторы перпендикулярны

a · b = 0

📊 Когда параллельны

x₁ / x₂ = y₁ / y₂

📊 Важные мысли

👉 векторы = координаты
👉 всё сводится к формулам

💬 Суть

Ты всегда делаешь:

-   переводишь в координаты
-   считаешь по формулам

Центральный угол равен дуге, на которую он опирается

Вписанный угол равен половине дуги, на которую опирается

Равен 90°

Свойство хорд

Равные хорды стягивают равные дуги

Касательные, проведённые из одной точки, равны

📌 ДЕЛИМОСТЬ

Определение

Целое число a делится на целое число b ≠ 0, если существует целое число
c, такое что a = b·c.

Если число a делится на число b, то мы будем использовать следующее
обозначение: a : b.

Признаки делимости

2
Число делится на 2 тогда и только тогда, когда его последняя цифра
является чётной (0 – чётное число).
Пример: число 4856 делится на 2, так как последняя цифра 6 — чётная.

3
Число делится на 3 тогда и только тогда, когда сумма его цифр делится на
3.
Пример: число 10815 делится на 3, так как сумма его цифр 1 + 0 + 8 + 1 +
5 = 15 делится на 3.

4
Число делится на 4, если две последние его цифры образуют число, которое
делится на 4.
Пример: число 8136 делится на 4, так как последние две цифры образуют
число 36, которое делится на 4.

5
Число делится на 5 тогда и только тогда, когда оно оканчивается на 0 или
на 5.
Пример: число 6910 делится на 5, так как последняя цифра 0.

8
Число делится на 8, если три последние цифры образуют число, которое
делится на 8.
Пример: число 58 296 делится на 8, так как последние три цифры образуют
число 296, которое делится на 8.

9
Число делится на 9 тогда и только тогда, когда сумма всех его цифр
делится на 9.
Пример: число 5238 делится на 9, так как сумма цифр 5 + 2 + 3 + 8 = 18
делится на 9.

10
Число делится на 10 тогда и только тогда, когда оно оканчивается цифрой
0.
Пример: число 740 делится на 10, так как оканчивается цифрой 0.

11
Число делится на 11 тогда и только тогда, когда разность суммы цифр,
стоящих в нечётных разрядах (разряды считаются с конца), и суммы цифр,
стоящих в чётных разрядах, делится на 11 или равна 0.
Пример: число 916327 делится на 11, так как сумма цифр, стоящих в
нечётных позициях, 7 + 3 + 6 = 16, сумма цифр чётных позиций 2 + 1 + 9 =
12, разность 16 − 12 = 4 не делится на 11 → не делится.

25
Число делится на 25 тогда и только тогда, когда последние две цифры
равны 00, 25, 50 или 75.
Пример: число 91675 делится на 25.

Натуральные числа

Натуральные числа — это числа, которые используются при счёте.
Примеры: 1, 2, 3, 4, …

Целые числа

Целые числа — это натуральные числа, числа противоположные им и 0.
Примеры: −1, −2, −3, …, 1, 2, 3, … и 0.

Рациональные числа

Рациональные числа — это числа, получающиеся в результате деления целого
числа на натуральное.
Примеры: 2/7, −5/3, −0,5, 4,89.

Иррациональные числа

Иррациональные числа — это действительные числа, не являющиеся
рациональными.
Примеры: √2, 2√3.

Простое число

Простое число — это натуральное число больше 1, имеющее ровно два
различных натуральных делителя: единицу и само себя.

Составное число

Составное число — натуральное число больше 1, не являющееся простым.

Важно: число 1 простым не является.

📌 СВОЙСТВА ДЕЛИМОСТИ

Пусть числа k, l, m, n, p, q — целые.

Свойство 1
Если m делится на n, то для любого числа k число km также делится на n.

Свойство 2
Если m делится на n и l делится на n, то m + l и m − l делятся на n.

Свойство 3
Если m делится на n и делится на p, то m делится на их произведение.

Свойство 4
Если m делится на n и p делится на q, то произведение mp делится на nq.

Свойство 5
Если m делится на составное число n = pq, то m делится на p и на q.

📌 ЧЁТНОСТЬ

Число называется чётным, если оно делится на 2.
Иначе — нечётное.

Свойства:

-   сумма двух чётных — чётная
-   сумма чётного и нечётного — нечётная
-   сумма нечётных — чётная
-   произведение чётного — чётное
-   произведение нечётных — нечётное

ПРОИЗВОДНЫЕ И ФУНКЦИИ

y = f(x)

f′(x₀) = k = tgα

Рассмотрим случай, когда k < 0.
Тогда k равен тангенсу угла α. Строим прямоугольный треугольник, но для
угла 180° − α.

k = tgα = −tg(180° − α) = −|AB| / |OB|

y = kx + b — уравнение касательной к графику функции y = f(x) в точке
x₀.
α — угол между касательной и положительным направлением оси x.

Если в окрестности точки x₀ функция f(x) возрастает, то f′(x₀) > 0, а
значит, у касательной коэффициент k > 0.

Если в окрестности точки x₀ функция f(x) убывает, то f′(x₀) < 0, а
значит, у касательной коэффициент k < 0.

Если в точке x₀ функция f(x) достигает локального минимума или
локального максимума, то касательная к графику функции в точке x₀
горизонтальна.

f′(x₀) = k = 0

k — коэффициенты k и b влияют на расположение прямых.

b > 0, k > 0
b < 0, k > 0
b > 0, k < 0
b < 0, k < 0

Прямая y = kx + b является касательной к графику функции y = f(x) в
точке с координатами (x₀; f(x₀)), если выполнены 2 условия:

1.  В точке x₀ прямая y = kx + b и график функции y = f(x) пересекаются,
    то есть при x = x₀ получаем
    f(x₀) = kx₀ + b.
2.  Значение производной функции y = f(x) в точке x₀ должно совпадать с
    коэффициентом k прямой y = kx + b, то есть:
    f′(x₀) = k.

В итоге получаем систему:
f(x₀) = kx₀ + b,
f′(x₀) = k.

Достаточное условие монотонности функции

Если f′(x) > 0 в каждой точке интервала (a; b), то функция f(x)
возрастает на этом интервале.

Если f′(x) < 0 в каждой точке интервала (a; b), то функция f(x) убывает
на этом интервале.

Дан график функции y = f(x)

Если нужно определить промежутки, где f′(x) > 0, то мы ищем промежутки,
где функция y = f(x) возрастает.

Если нужно определить промежутки, где f′(x) < 0, то мы ищем промежутки,
где функция y = f(x) убывает.

Если нужно определить точки, где f′(x) = 0, то мы ищем точки минимума
или максимума функции y = f(x).

Дан график производной функции y = f′(x)

Если нужно определить промежутки, где f′(x) > 0, то мы ищем промежутки,
на которых график производной находится выше оси Ox или, иначе говоря,
точки графика с положительной координатой по оси Oy.

Если нужно определить промежутки, где f′(x) < 0, то мы ищем промежутки,
на которых график производной находится ниже оси Ox или, иначе говоря,
точки графика с отрицательной координатой по оси Oy.

Если нужно определить точки, где f′(x) = 0, то мы ищем точки, в которых
график производной пересекает ось Ox.

Определения

Точки, в которых производная f′(x) равна 0 или не существует, называются
критическими точками функции f(x).

Экстремум функции — минимум или максимум этой функции.

Точка экстремума x₀ — точка, в которой функция достигает минимума или
максимума.

Необходимое условие экстремума

Если x₀ — точка экстремума функции f(x), то f′(x₀) = 0.

То есть, во всех точках, где f(x) достигает локального min/max,
производная равна 0.

Достаточное условие экстремума

Пусть x₀ — точка, в которой f′(x) = 0.
Если производная при переходе через точку x₀ меняет свой знак с плюса на
минус, то x₀ — точка максимума.

Если производная при переходе через точку x₀ меняет свой знак с минуса
на плюс, то x₀ — точка минимума.

Алгоритм поиска наибольшего/наименьшего значения функции y = f(x) на отрезке [a; b]

1.  Находим область определения функции f(x).
2.  Считаем производную f′(x) функции f(x).
3.  Решаем уравнение f′(x) = 0. Корни уравнения — критические точки.
4.  Наносим критические точки, попавшие в отрезок [a; b], на числовую
    прямую и расставляем знаки f′(x) производной функции f(x) в
    полученных промежутках.
5.  Проанализируем ситуации.
6.  Подставляем точку x₀, в которой достигается наибольшее/наименьшее
    значение, в функцию f(x). Полученное значение есть ответ.
    Если точек, в которых может достигаться наибольшее/наименьшее
    значение функции несколько, считаем значение функции f(x) в каждой
    из них, а затем, сравнивая найденные значения, выбираем из них
    наибольшее/наименьшее.

Основные формулы производных

1.  c′ = 0, где c — константа
2.  (x)′ = 0
3.  (e^x)′ = e^x
4.  (e^x)′ = e^x
5.  (√e)′ = 0
6.  (ln 7)′ = 0

Производная от постоянной величины всегда равна 0

ТЕОРИЯ ВЕРОЯТНОСТЕЙ

Вероятность события

Вероятность события — это числовая характеристика, которая отражает
степень уверенности в том, что это событие произойдёт.

В общем случае мы проводим серию одинаковых экспериментов, в каждом из
которых может произойти один из N исходов (при этом все исходы
встречаются примерно поровну). Обозначим за A некоторый исход (мы также
будем называть его элементарным событием) эксперимента. Вероятностью
элементарного события A будем называть число:

P(A) = 1 / N

Например, при бросании монетки есть всего два элементарных исхода (либо
выпадет орёл, либо выпадет решка), поэтому вероятность каждого из
исходов равна 1/2.

В эксперименте с бросанием кубика у нас уже может быть 6 исходов (выпало
число от 1 до 6), поэтому вероятность каждого из них равна 1/6.

Мы можем искать вероятность не одного элементарного события, а сразу
нескольких. Пусть у нас есть N возможных исходов и мы выбираем из них
N(A), которые будем называть благоприятными. Событие A будет состоять в
том, что в случайном эксперименте произошёл один из N(A) благоприятных
исходов. Тогда вероятность события A будем называть число:

P(A) = N(A) / N

Пример:
На клавиатуре телефона 10 цифр, от 0 до 9. Какова вероятность того, что
случайно нажатая цифра окажется чётной?

Решение:
Всего у нас 10 возможных элементарных исходов (нажата цифра от 0 до 9).
Вероятности этих исходов равны. Благоприятных у нас 5 исходов (нажата
цифра 0, 2, 4, 6, 8). Значит, вероятность того, что случайно нажатая
цифра окажется чётной, равна 5/10 = 1/2 = 0,5.

Ответ: 0,5.

Свойства вероятности

Вероятность — это число в промежутке от 0 до 1 (0 ≤ P ≤ 1).

Сумма вероятностей всех элементарных исходов эксперимента равна 1.

Пусть у нас есть событие A. За Ā обозначим событие «событие A не
произошло». Тогда верно следующее равенство:

P(Ā) = 1 − P(A)

События A и Ā называются противоположными.

Событие называется достоверным, если оно обязательно наступит в
результате данного опыта. Его вероятность равна 1.

Событие называется невозможным, если оно заведомо не произойдёт в
результате проведения опыта. Его вероятность равна 0.

Задачи на монеты

Подбросим обычную монету.
Элементарными исходами является выпадение стороны. Всего их N = 2.

P₀ — вероятность выпадения орла
P₁ — вероятность выпадения решки

Благоприятных событий N(A) = 1

P₀ = P₁ = 1/2 = 0,5

Задачи на кубики

Бросаем игральный кубик.
Элементарными исходами является выпадение граней кубика. Всего их N = 6.

P₂ — вероятность выпадения двойки
P₃ — вероятность выпадения тройки

Благоприятных событий N(A) = 1

P₂ = 1/6
P₃ = 1/6

Независимые события

Если вероятность события A не зависит от события B (то есть P(A|B) =
P(A)) и вероятность события B не зависит от события A (то есть P(B|A) =
P(B)), то события A и B называются независимыми.

В этом случае верна следующая формула:

P(A ∩ B) = P(A) · P(B)

Вероятность произведения двух независимых событий равна произведению их
вероятностей.

Зависимые события

События являются зависимыми, если либо P(A|B) ≠ P(A), либо P(B|A) ≠
P(B).

Тогда:

P(A ∩ B) = P(A) · P(B|A)

Вероятность произведения двух зависимых событий равна произведению
вероятности одного из них на вероятность второго при условии, что первое
произошло.

Несовместные события

Пусть события A и B не могут происходить одновременно, они называются
несовместными.

Событие A ∪ B — это событие, состоящее в том, что произошли либо A, либо
B, либо сразу оба.

Тогда:

P(A ∪ B) = P(A) + P(B)

Вероятность суммы двух несовместных событий равна сумме их вероятностей.

Совместные события

Если события A и B могут происходить одновременно, то они являются
совместными.

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Вероятность суммы двух совместных событий равна сумме их вероятностей
без вероятности их совместного появления.

Условная вероятность

P(B|A) — это вероятность события B при условии, что событие A произошло.

Формула:

P(B|A) = P(A ∩ B) / P(A)

Формула Бернулли

Пусть мы проводим испытание, в котором могут быть два исхода (успех или
неудача), при этом вероятность успеха равна p, а вероятность неудачи
равна q = 1 − p.

Тогда если мы проводим n испытаний, то вероятность того, что k раз
выпадет успех, равна:

Pₙ(k) = Cₙᵏ · pᵏ · qⁿ⁻ᵏ = Cₙᵏ · pᵏ · (1 − p)ⁿ⁻ᵏ

Задача про круглые столы

За круглый стол на 41 стул в случайном порядке рассаживают 39 мальчиков
и 2 девочки. Найдите вероятность того, что между двумя девочками будет
сидеть один мальчик.

Решение:
Пусть первая девочка займёт произвольное место. Тогда для второй девочки
остаётся 40 свободных стульев, из которых ей подходит 2 (т.к. нужно
чтобы между двумя девочками сидел один мальчик, то получается, что
подходит два места «через одного» относительно первой девочки).

Соответственно имеем:
2 / 40 = 0,05

Ответ: 0,05.

Задача про монету

Симметричную монету бросают 10 раз. Во сколько раз вероятность события
«выпадет ровно 5 орлов» больше вероятности события «выпадет ровно 4
орла»?

Решение:
С помощью формулы Бернулли найдём вероятность событий «выпадет ровно 5
орлов» и «выпадет ровно 4 орла».

P₁₀(5) = C₁₀⁵ · (1/2)¹⁰
P₁₀(4) = C₁₀⁴ · (1/2)¹⁰

Отношение вероятностей:

C₁₀⁵ / C₁₀⁴ = 252 / 210 = 1,2

Ответ: 1,2.

Задача на кофейные автоматы

В торговом центре два одинаковых автомата продают кофе. Вероятность
того, что к концу дня в первом автомате закончится кофе, равна 0,1.
Вероятность того, что кофе закончится во втором автомате, такая же.
Вероятность того, что кофе закончится в двух автоматах, равна 0,03.
Найдите вероятность того, что кофе останется в двух автоматах.

Решение:
У нас есть события:

1.  кофе закончится в первом автомате
2.  кофе закончится во втором автомате

Вероятности каждого события равны 0,1.
Вероятность их пересечения равна 0,03.

Имеем:
0,1 + 0,1 − 0,03 = 0,17

А событие «кофе останется в двух автоматах» — противоположное, значит:

1 − 0,17 = 0,83

Ответ: 0,83.

Задача на фломастеры

В коробке 5 синих, 9 красных и 11 зелёных фломастеров. Случайным образом
выбирают два фломастера. Найдите вероятность того, что окажутся выбраны
один синий и один красный фломастеры.

Решение:
Благоприятными являются две ситуации:

1.  сначала синий, потом красный
2.  сначала красный, потом синий

Всего 25 фломастеров.

P = (5/25 · 9/24) + (9/25 · 5/24)

= 2 · (5/25 · 9/24)
= 2 · (1/5 · 3/8)
= 2 · 3/40
= 6/40 = 3/20 = 0,15

Ответ: 0,15.

Задача про артиллерию

При артиллерийской стрельбе автоматическая система делает выстрел по
цели. Если цель не уничтожена, то система делает повторный выстрел.
Выстрелы повторяются до тех пор, пока цель не будет уничтожена.

Вероятность уничтожения цели при первом выстреле равна 0,4, а при каждом
последующем — 0,6.

Сколько выстрелов потребуется для того, чтобы вероятность уничтожения
цели была не менее 0,8?

Решение:
Вероятность уничтожения с первого выстрела = 0,4

Вероятность уничтожения со второго выстрела:
0,6 · 0,6 = 0,36

Суммарно:
0,4 + 0,36 = 0,76 < 0,8

Тогда считаем третий:
0,6 · 0,4 · 0,6 = 0,144

Итого:
0,76 + 0,144 = 0,904 > 0,8

Значит, нужно 3 выстрела.

Ответ: 3.
